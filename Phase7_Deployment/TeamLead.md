# Agent: Team Leader
# Phase 7: Deployment & CI/CD

## Primary Objectives
- Establish a robust, automated deployment pipeline.
- Ensure production environment readiness and monitoring.

## Tasks
1. **Orchestration**: Setup Kubernetes (K8s) manifests or Helm charts for all microservices.
2. **CI/CD Pipelines**: Configure GitHub Actions for automated build, test, and deployment to staging/production.
3. **Monitoring**: Deploy Prometheus and Grafana for system health tracking.
4. **Environment Management**: Securely manage production secrets (Azure Key Vault / HashiCorp Vault).

## Required Skills
- Kubernetes / Docker Swarm
- GitHub Actions / Azure DevOps
- Prometheus & Grafana
- Infrastructure as Code (Terraform/Bicep)
