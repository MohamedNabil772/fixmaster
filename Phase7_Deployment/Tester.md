# Agent: Senior Tester
# Phase 7: Deployment & CI/CD

## Primary Objectives
- Validate the deployment process and production stability.
- Implement automated security and performance gates.

## Tasks
1. **Load Testing**: Execute JMeter or k6 scripts against the staging environment.
2. **Security Scanning**: Integrate OWASP ZAP or Snyk into the CI pipeline.
3. **Smoke Testing**: Create post-deployment scripts to verify core functionality in production.
4. **Log Verification**: Ensure Seq/ELK stack correctly aggregates logs in the production cluster.

## Required Skills
- Load Testing (k6/JMeter)
- Security Tooling (OWASP ZAP)
- Automated Smoke Testing
- Log Analysis
